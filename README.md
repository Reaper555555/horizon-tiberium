# Tiberium for Horizon

**Current version: 0.1.23**

## Growth
- 3 visual styles (a/b/c), each with 5 **scaled** stages (growth by size, not model swap)
- Stage 5 ~2 blocks tall visually (single block)
- Field spread sideways; rare single tower per 64x64 region
- Wall growth outward; no floating crystals
- Water absorbed only on direct contact

## Install
`horizon-mods/tiberium.hmod` + `horizon-native-mods/tiberium-0.1.23.hnmod` then Native Build.

Repo: sources updated alongside install zips in chat.
