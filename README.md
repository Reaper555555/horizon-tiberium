# Tiberium for Horizon

Мод тиберия для [Horizon](https://github.com/horizon-rust/horizon) — Minecraft Java Edition 26.3,
переписанного на Rust.

Тиберий — это кристаллическая зараза, которая расползается по земле, высушивает почву, строит
шестигранные массивы и вызывает ионные штормы. Звуковой эффект и биом в привычном смысле недоступны
на платформе, поэтому атмосфера сделана через туман, частицы и молнии.

## Установка

1. Скачайте `tiberium-0.2.0-install.zip` из релизов.
2. Распакуйте его в папку Horizon (ту, где лежит `options.txt`):

```
horizon-mods/tiberium.hmod
horizon-native-mods/tiberium-0.2.0.hnmod
```

3. Запустите Horizon. Лаунчер сам соберёт нативную часть (нужен Rust 1.99.1, скачается сам) и
   спросит подтверждение доверия нативному коду.

Мод собран под Horizon `66f3981f522b24c250b21523a70080965b940424` (API хуков 411) и mixins
`e8cd0aa38cffef49cb2e088ef716baa107148c02`. После обновления Horizon закрепление нужно обновить.

Если готового архива под рукой нет, его можно собрать прямо из репозитория:

```bash
git clone --branch fix/v0.2.0-5 https://github.com/Reaper555555/horizon-tiberium.git
cd horizon-tiberium/packages
sh decode-install.sh          # соберёт tiberium-0.2.0-install.zip и проверит sha256
```

Архив в base64 разбит на части `packages/tiberium-0.2.0-install.zip.b64.part*` (репозиторий
остаётся текстовым), а `decode-install.sh` склеивает их, декодирует, сверяет контрольную сумму
и состав архива перед распаковкой.

## Что внутри

**Поля тиберия.** Кристаллы растут преимущественно вширь: расползаются по почве, закрепляются на
стенах и потолке. Всего 20 вариантов формы и наклона, каждый ещё и поворачивается — соседние
кристаллы не выглядят одинаково.

**Рост без стопки блоков.** Кристалл растёт сменой модели: 7 стадий (p0…p6), сечение растёт с 4 до
12 px, поэтому рост виден глазом. Кристалл всегда один блок — он вырастает размером, а не стопкой,
и кристаллы не растут друг на друге. Если под кристаллом воздух — он падает на землю, а на стене или
потолке держится.

**Коллизия по форме.** У блока кристалла свой контур и своя коллизия, зависящие от стадии роста:
маленький кристалл — это узкий столбик, зрелый — почти полный блок. Форма и коллизия считаются из
настоящей модели, так что по кристаллу можно ходить, а не проходить насквозь. У блока массива
коллизия тоже своя: сердцевина — целый блок, бок — половина.

**Шестигранные массивы.** Когда поле становится широким (25 кристаллов рядом), из одного из них
начинает расти крупная структура. Каждый её блок — шестигранная колонна, и массив читается как
связанные между собой колонны; боковые блоки повёрнуты, поэтому край скошенный и без зазоров.
Сечение — ромб с вытянутыми концами, площадь случайная: от 5 до 23 клеток. Все слои одинаковые
(массив не сужается вверх), но каждый третий слой сдвигается на клетку в сторону наклона —
массив заваливается, и направлений наклона восемь. Блоки ставятся по одному за две секунды:
слой заполняется целиком, и только потом начинается следующий. Если под опорным кристаллом пусто,
массив дотягивается до земли и стоит на ней. На вершине — кристаллический гребень.

**Осушение.** Почва вокруг сохнет: трава → земля → грунт → заражённая почва `tiberium:tainted_soil`.
Каменем она не заканчивается: по камню тиберия не расползается.

**Ионный шторм.** Там, где тиберия много, поднимается шторм: зелёный туман, тряска камеры и молнии,
бьющие рядом с игроком. Молнии не поджигают землю.

**Кристаллы на стенах.** Настенный кристалл прижимается к стене, как факел, а под потолком —
свисает с него. Для этого у блока есть отдельные настенные формы: сторона задана самой формой,
поэтому кристалл всегда стоит вплотную к стене.

**Заражение.** Настоящее отравление (`minecraft:poison`), а не надпись на экране. Заражён игрок в
поле тиберия и игрок, поднявший осколок без капсулы. Полный био-костюм снимает заражение. Осколок
в запечатанной капсуле безопасен.

**Добыча.** Кристалл и массив копаются только киркой, минимум железной, и ведут себя как обсидиан:
без инструмента — долго и без дропа. С киркой падают осколки.

## Сборка из исходников

```bash
python3 tools/gen_assets.py   # модели, бло��стейты, текстуры
python3 tools/build.py        # проверки + dist/*.hmod, *.hnmod, install.zip
python3 tools/package.py      # packages/: архив, base64-части, decode-install.sh
python3 tools/preview.py      # превью моделей в изометрии (dist/preview.png)
python3 tools/preview.py --scene spire -o dist/spire.png   # крупная структура целиком
```

Нативную часть можно проверить без сборки всей игры:

```bash
cd tools/typecheck && cargo test --offline
```

Тесты ловят зависание серверного потока (если мьютекс снова начнут держать во время роста поля,
тест упадёт по таймауту с сообщением «тик игрока завис») и проверяют правила роста: кристалл падает,
не растёт выше двух блоков, поле расползается вширь, крупная структура растёт из существующего
кристалла и не появляется вся сразу.

`build.py` проверяет, что каждая комбинация свойств блока имеет модель (иначе игра рисует
«чёрно-фиолетовый» отсутствующий блок), что PNG целые, что иконки предметов доходят до вкладки
креатива, что манифест совпадает с API Horizon и что именованные хуки бандла существуют в каталоге
`native-hooks.json`.

## Ограничения платформы

* **Биома нет.** Horizon не поддерживает новые биомы из паков, поэтому тибериевая зона — это
  блоки, туман и эффект, а не запись в реестре биомов.
* **Погода не задаётся.** Ванильной погоды нет, ионный шторм — собственный эффект.
* **Блок выше блока невозможен.** Формат модели ограничен кубом 1×1×1, поэтому массив — это стек
  блоков, а «хвост» сужается внутри блока.
